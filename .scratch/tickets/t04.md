#1

## What to build

Learner profiles from end to end:
- In the Parent area, the Parent creates, edits and removes Learners, each with a name, grade, an assigned Curriculum (from the loaded Curricula) and an optional PIN.
- On the login screen, a Learner picks their profile, enters their PIN if one is set, and lands on an (empty for now) Learner home screen.
- A logged-in Learner can never reach Parent endpoints.

## Acceptance criteria

- [ ] The Parent can create, edit and remove Learners. The assigned Curriculum must be a valid loaded Curriculum.
- [ ] The Learner login screen lists profiles. A profile with a PIN requires the correct PIN, which is stored hashed.
- [ ] A Learner session gets "forbidden" on every Parent endpoint.
- [ ] Seam 1 API tests cover Learner create, edit and remove, PIN login success and failure, and role separation.
