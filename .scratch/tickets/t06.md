## What to build

An OpenAI adapter behind the existing provider interface. The Parent can choose OpenAI and a model in the Parent area, using a key from OpenAI's environment variable, and get the same "test connection" feedback as for Anthropic.

## Acceptance criteria

- [ ] OpenAI appears as a provider option with a short list of models.
- [ ] Streamed chat and structured output work through the same interface, and token usage is reported.
- [ ] The key comes only from the environment variable. A missing or rejected key shows the same clear messages as for Anthropic.
- [ ] No tutoring logic changes to support the new provider.
