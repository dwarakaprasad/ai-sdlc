## What to build

Parent oversight and limits:
- **Progress view per Learner:** Goals met, Quiz scores per attempt, overdue Goals, Flagged Goals, and orphaned Goals (whose Lesson key no longer exists in the Curriculum).
- **Transcripts:** the Parent can read every Session transcript.
- **Resolving a Flagged Goal:** the Parent can retry it, skip it, or mark it met.
- **Orphaned Goals:** the Parent can re-point them to another Lesson or remove them.
- **Daily token cap (optional):** the Parent sees usage per day. Once the cap is reached, the Learner gets a friendly "that's enough for today" message instead of a Tutor reply.
- **Break prompt:** shown to the Learner after a configurable number of minutes in a Session (default 25).

## Acceptance criteria

- [ ] The progress view shows Goals met, attempt scores, overdue Goals, Flagged Goals and orphaned Goals for each Learner.
- [ ] The Parent can open any Session transcript.
- [ ] Retrying, skipping or marking met a Flagged Goal behaves correctly. Marking met triggers normal progression.
- [ ] Orphaned Goals appear after a Lesson is renumbered or removed, and can be re-pointed or removed.
- [ ] With a daily token cap set, Tutor turns stop with a friendly message once usage reaches the cap, and resume the next day. Usage per day is visible to the Parent.
- [ ] The break prompt appears after the configured number of minutes.
- [ ] Seam 1 tests cover each of the above.
