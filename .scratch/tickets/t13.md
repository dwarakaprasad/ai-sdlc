## What to build

Make the repo ready for other parents to fork and run:
- A Docker Compose setup that runs the app with the data folder and the Curriculum folder mounted.
- A `.env` example listing each provider's API-key variable.
- A README covering forking, drafting a Curriculum with the Curriculum Assistant (or by hand), `curriculum:check`, setting the API key, running with `npm start` or Docker, and first-run Parent setup.
- The MIT licence.

## Acceptance criteria

- [ ] `docker compose up` starts the app. Data and Curricula persist via mounted volumes, and the API key is passed through the environment.
- [ ] The `.env` example documents every supported provider variable, and the real `.env` is git-ignored.
- [ ] The README takes a new Parent from fork to a first Session using the North Colonie sample.
- [ ] A LICENSE file contains the MIT licence.
