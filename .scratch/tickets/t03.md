## What to build

The two things a Parent who forks the repo starts from:
1. A **sample Curriculum** for North Colonie Central School District, Grade 6, Math and ELA, Term 1, written in the Curriculum format and passing `curriculum:check`.
2. The **Curriculum Assistant** (ADR 0004): agent-agnostic markdown instructions, linked from `AGENTS.md`, that let a Parent's own coding agent draft or edit a Curriculum. The agent interviews the Parent (district, grade, school year, Subjects, Terms, Curriculum References), uses those references, writes files in the Curriculum format, and keeps running `curriculum:check` until it passes. Also a thin Claude Code skill wrapper that points at the same instructions.

## Acceptance criteria

- [ ] The North Colonie Grade 6 Math and ELA Term 1 sample exists, records its Curriculum References, and passes `curriculum:check`.
- [ ] A test asserts that the shipped sample is valid.
- [ ] The Curriculum Assistant instructions exist and are linked from `AGENTS.md`. They name `curriculum:check` as the definition of done and use `CONTEXT.md` vocabulary.
- [ ] A Claude Code skill wrapper invokes the same instructions, so the content isn't duplicated.
