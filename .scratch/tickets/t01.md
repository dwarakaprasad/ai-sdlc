## What to build

The base project of Home Tutor, working end to end. `npm start` runs one Node process: a Vite + React front end served by a Hono API server, with SQLite via Drizzle in a git-ignored data folder (ADR 0003). The first visit asks the Parent to set a password. After that the Parent logs in to an empty Parent area. This ticket also sets up the main test seam: the Hono app called in-process against an in-memory SQLite database, ready for later tickets to add a fake LLM provider and Curriculum fixtures.

## Acceptance criteria

- [ ] `npm start` serves the React app and the API from one process. The data folder is created on first run and is git-ignored.
- [ ] First run: the Parent sets a password, stored hashed. Later visits require logging in. A logged-in Parent sees an empty Parent area.
- [ ] Parent routes reject requests that aren't logged in.
- [ ] An in-process API test setup (in-memory SQLite, no network listener) exists, with tests covering first-run password setup, login and route protection.
- [ ] UI text lives in one place (English only), ready for translation later.
