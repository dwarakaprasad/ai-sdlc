## Parent

#1

## What to build

Tools for the Parent to plan Goals:
- The Parent enters a Term end date for a Learner and Subject, and Target Dates are spread evenly across the remaining Lessons in Curriculum order. Goals are created for any Lessons that don't have one yet.
- The Parent can edit any single Target Date, and reorder, skip or insert Goals.

## Acceptance criteria

- [ ] Entering a Term end date creates or updates Goals for the remaining Lessons, with evenly spread Target Dates that land on or before the end date.
- [ ] Editing one Target Date leaves the other dates unchanged.
- [ ] Reorder, skip and insert change which Goal is current on the Learner home screen.
- [ ] Seam 1 tests cover spreading (including uneven division), editing a single date, reordering, skipping and inserting.
