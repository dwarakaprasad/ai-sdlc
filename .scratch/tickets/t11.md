## What to build

Automatic progression through the Curriculum:
- When a Lesson Goal is met, the next Lesson in Curriculum order becomes the Learner's next Goal for that Subject, unless the Parent has already queued one.
- When every Lesson in a Unit is met, a **Unit Test** Goal is created. It runs like a Lesson Quiz but covers all of the Unit's Learning Objectives, with the same feedback, pass mark, re-teaching and attempt cap.

## Acceptance criteria

- [ ] Meeting a Lesson Goal makes the next Lesson in Curriculum order the current Goal, and respects any Goals the Parent has already queued.
- [ ] Meeting the last Lesson Goal in a Unit creates a Unit Test Goal.
- [ ] Unit Test questions are drawn from all of the Unit's Learning Objectives. Passing marks the Unit Test Goal met, and progression continues into the next Unit.
- [ ] Seam 1 tests cover moving to the next Lesson, creating the Unit Test, failing and then passing a Unit Test, and the end of a Term.
