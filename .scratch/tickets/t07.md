## What to build

Goals from end to end:
- In the Parent area, the Parent sets a Goal for a Learner: a Lesson from that Learner's Curriculum, plus a Target Date.
- On the Learner home screen, the Learner sees one current Goal card per Subject, earliest Target Date first.
- Overdue status (Target Date passed and Goal not met) is calculated when needed, not stored. The Parent sees it plainly; the Learner sees gentle wording ("let's catch up").
- Goals are stored with: Learner, Subject, Lesson key, kind (lesson or unit-test), order, Target Date and status (active, met, flagged or skipped).

## Acceptance criteria

- [ ] The Parent can create a Goal for a Learner from any Lesson in that Learner's Curriculum, with a Target Date.
- [ ] The Learner home screen shows one current Goal per Subject, ordered by Target Date.
- [ ] Overdue Goals are flagged in the Parent area and shown gently to the Learner. Nothing else changes automatically.
- [ ] Seam 1 tests cover Goal creation, current Goal per Subject, ordering and overdue status, using a Curriculum fixture folder.
