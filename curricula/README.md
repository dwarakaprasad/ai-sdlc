# Curricula

Put one folder per Curriculum here. See [docs/curriculum-format.md](../docs/curriculum-format.md) for the format, and run `npm run curriculum:check` to validate.

`north-colonie-grade-6/` is a sample to copy from. To draft or edit a Curriculum with your coding agent, point it at [docs/curriculum-assistant.md](../docs/curriculum-assistant.md) (Claude Code: `/curriculum-assistant`).
